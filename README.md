# ⚔️ ArguMind

> **TRUTH IS NOT SPOKEN · IT IS PROVEN**

An AI-powered debate platform that listens, fact-checks, and judges arguments in real time.

🔴 **Live** → [app.argumind.space](https://app.argumind.space) need to turn on the cloudfare tunnel

---

## What It Does

- 🎙️ Real-time speech transcription via Deepgram
- 🔍 AI fact-checking with Groq LLaMA 3.3 70B + Tavily
- ⚖️ Automated scoring — TRUE / FALSE / PARTIALLY TRUE
- 📊 Deep post-debate analysis with strengths & weaknesses
- 🌐 Live video debate rooms via WebRTC

React · Node.js · FastAPI · MongoDB · Socket.IO · WebRTC · Deepgram · Groq · Cloudflare
